# Web Application Dashboard Project

A simple, front-end web application featuring user and administrator dashboards along with a centralized login interface.

## 🚀 Features

* **User Dashboard:** Dedicated interface tailored for regular user access and metrics.
* **Admin Dashboard:** Administrative panel built for system oversight and management tasks.
* **Secure Structure:** Initial repository layout equipped with environment configuration (`.env`) and standard git isolation (`.gitignore`).

## 📁 Repository Structure

* `login.html` — The main entry point and authentication page for the application.
* `user-dashboard.html` — The dashboard layout displayed to standard users upon logging in.
* `admin-dashboard.html` — The elevated management view intended strictly for administrators.
* `.env` — Local environment variables (do not commit production secrets here).
* `.gitignore` — Specifies intentionally untracked files that Git should ignore.
